Inspiration / Documentation

Projects I looked at

When beginning this project, I looked at several developer blogs and documentation-style websites to understand how technical blogs are structured visually.

Some of the main references I looked at were:

  • https://www.11ty.dev/
  • https://www.11ty.dev/blog/
  • https://www.zachleat.com/web/eleventy/

What stood out to me about these sites was their clean layout, strong hierarchy, and intentional use of spacing. The Eleventy website in particular uses a simple structure where content is easy to read and navigate, which made it feel professional and functional.

I also paid attention to how posts were organized, how metadata was displayed, and how the homepage introduced the site.

What artists or designers I referenced

Instead of referencing traditional artists, my inspiration came from developer focused websites and technical interfaces.

These included:

  • developer blogs
  • documentation websites
  • terminal interfaces

Many of these sites use dark backgrounds, monospace fonts, and structured layouts to communicate a technical identity. This influenced my decision to create a tech themed blog that feels like a development log or system interface.

How I landed on my aesthetic

After reviewing multiple examples, I decided to create a tech-inspired aesthetic that reflects the identity of a developer blog.

My final aesthetic included:

  • dark background
  • structured grid layout
  • card-based post system
  • monospace accents

I chose this aesthetic because it visually communicates technology, structure, and professionalism.

I also wanted the blog to feel intentional rather than default, and changing the layout helped achieve that goal.

Keywords I used when searching for references

Some of the keywords I used were:

  • developer blog design
  • tech blog layout
  • terminal inspired website
  • developer portfolio blog
  • documentation website design

I chose these keywords based on the direction I wanted my blog to go. Since my theme was technology focused, I used words related to developers, terminals, and technical interfaces.

These keywords helped me find layouts and visual styles that aligned with my goal.

They also helped me understand how professional developer blogs are designed.

Technical Process

Experiments and Iteration

During this project, I experimented with both layout files and CSS files to understand how Eleventy controls structure and styling.

One of my first experiments was editing only the CSS in css/index.css. I changed colors, spacing, and font sizes. While this made small visual differences, the overall layout of the homepage remained the same. This helped me realize that CSS alone could not change the structure of the site.

Because of this, I began experimenting with the layout file which originally used the default Eleventy post list, which appeared as a simple vertical list.
