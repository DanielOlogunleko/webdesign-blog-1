Anime Quiz Live Site

For this project, my group and I were tasked with using an API for its unintended purpose and incorporating a NeDB database. Our concept was to build a personality based quiz that analyzes a user’s decision making style and maps it to psychological archetypes represented through anime characters.

Instead of using anime data in its typical way (for browsing shows or characters), we repurposed it as a reflective system that connects personality traits to anime archetypes.

My Role

I was incharge of creating the quiz. Making sure html, javascript and every link was good and not broken. I was responsible for building the quiz logic and handling how user input is processed. I created a weighted scoring system that takes user answers and maps them to different psychological archetypes.

Challenges I faced

One of the main challenges was figuring out how to translate user answers into meaningful archetypes. Initially, it was difficult to map answers directly to results, so I redesigned the system using a weighted scoring model, which made the results more flexible and accurate. Another challenge was handling the communication between the client and server using fetch(). Making sure the data was properly sent, processed, and returned required debugging and testing.

Additionally, working with deployment on the DigitalOcean droplet was a challenge, especially with configuring the server and ensuring the project ran correctly outside of the local environment.
